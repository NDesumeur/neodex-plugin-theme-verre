# Frosted glass theme for NeoDex

Modern: translucent blurred panels, rounded corners, crisp text.

*Version française : [README.md](README.md)*

Install it from NeoStore, **Themes and decors** shelf, then pick it in Settings › Appearance.

- Changes NeoDex's colours, fonts and frames. The background decor stays the one you chose.
- Works on PC and on phone. Needs NeoDex 3.3.9 or later.
- Asks for no permission and holds no code: nothing comes from the Internet.

Before NeoDex 3.3.9, this theme came with NeoDex. It is now apart so NeoDex stays sober by default.
